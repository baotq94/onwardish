サイト: https://onwardish.com

`最終更新日: 2026-02-09`

onwardish（以下「当サイト」）は、当サイトの運営にあたり取得する情報を適切に取り扱い、プライバシー保護に努めます。  
当サイトは **日常の記録 / 学習メモ / 技術ブログ / ポートフォリオ / 個人開発（ペットプロジェクト）** の公開を目的とした個人サイトです。

---

### 取得する情報

当サイトでは、以下の情報を取得・送信することがあります。

- アクセスログ（IPアドレス、ユーザーエージェント、参照元URL、閲覧日時、閲覧URL、ステータスコード等）
- アクセス解析（GoatCounter）：ページ閲覧状況等の統計情報（例：閲覧ページ、参照元、ブラウザ/OS、言語、画面幅、位置情報（国/地域レベル）等 ※設定により変動）
- コメント機能（giscus / GitHub Discussions）：コメント投稿時に必要となる情報（GitHubアカウント情報、コメント内容等）は、GitHub側で処理・保存されます

---

### 利用目的

取得した情報は、以下の目的で利用します。

- 不正アクセス・スパム等の防止、セキュリティ確保
- サイト改善（アクセス状況の把握を含む）
- コメント機能の提供・運用（giscus / GitHub Discussions）

---

### 第三者への提供

当サイトは、法令に基づく場合を除き、本人の同意なく個人情報を第三者に提供しません。  
ただし、サイト運営に必要な範囲で、ホスティング事業者等の業務委託先や、下記の外部サービスに取り扱いを委託・送信する場合があります。

---

### アクセス解析・Cookie・外部送信

当サイトでは、以下の外部サービスを利用しています。

- **GoatCounter（アクセス解析）**
  - 送信される情報: 閲覧ページ、参照元、ブラウザ/OS、言語、画面幅、位置情報（国/地域レベル）等（設定により変動）
  - 送信先: GoatCounter（当サイトが利用する解析エンドポイント）
  - 利用目的: アクセス解析、サイト改善、運用状況の把握
  - オプトアウト等: コンテンツブロッカー（広告/トラッキングブロッカー等）で解析スクリプト/エンドポイントをブロックすることで送信を停止できます

- **giscus（コメント機能: GitHub Discussions）**
  - 送信される情報: コメント機能の表示/投稿に必要な情報（GitHubアカウント情報、コメント内容等）
  - 送信先: giscus / GitHub（GitHub Discussions）
  - 利用目的: コメント機能の提供・運用、モデレーション
  - 補足: コメント投稿には GitHub へのログインおよび giscus アプリへの認可が必要です。コメントは GitHub Discussions に保存されます
  - オプトアウト等: コメント機能を利用しない、またはコンテンツブロッカーでコメント領域の読み込みをブロックしてください

※外部サービス側で Cookie / localStorage 等が利用される場合があります。詳細は各サービスのポリシーをご確認ください。
