このブログはテンプレート [tailwind-nextjs-starter-blog](https://github.com/timlrx/tailwind-nextjs-starter-blog) から複製しました。 このソースは最初は問題ありませんでしたが、しばらく使用すると、次のような問題が発生しました。

- 使用するライブラリが多すぎます。 依存関係が多すぎるため、古いコア ライブラリを更新できない

- mdx から記事を構築するコードが複雑すぎる

- テーマはライトとダークの 2 つだけです

- SEO の最適化がうまくいっていない

ゼロから作るのは楽しい！

- 解決すべき問題があると嬉しい

- 新しい知識を喜んで学ぶ

- 破壊的な実験をする機会を得てうれしい

ぜひ試してみてはいかがでしょうか。 このペットプロジェクトを一緒に計画しましょう:D.

## ブログ サイトには何が必要ですか?

ブログに必要な基本機能:

- 投稿

- タグ（記事を分類）

- About(著者情報)

ただし、彼のブログに関しては。 制限なく自由に作成できるため、次のような興味深い機能をいくつか思いつきました。

- Spotify のステータス

- 投稿ビュー

- コードスニペット

- 今日は学びます (毎日学んだことを保存します)

- インタラクティブな記事。 例: 記事にコードを挿入します

...

そして、私の古いブログが遭遇した問題を解決することが重要です。

## インターフェースはどのようなものであるべきでしょうか?

私はデザイナーについては何も知らないので、インターフェイスを盗むことが最も合理的な解決策のようです:))。 私が選ぶ参考ソースはドリブルとビハンスです。 ただし、非常にミニマリストであるため、主にインターフェイスは古いブログのままにしています。

次に、適切な色を選択します。[Rosé Pine](https://rosepinetheme.com/) パレットは、IT グループ チャットで見つけました。 このカラーパレットはユーザーに心地よい感覚をもたらします。

![ロゼパイン](/static/images/2022/blog-tutorial/rosepine.png)

最後に、フォントを選択します。

- タイトルは **Barlow**
- コンテンツの **Barlow Condensed**
- コード内の **Consolas** フォント。 エディターで使用しているフォント

## どのテクノロジーを選択すればよいでしょうか?

欠かすことのできないテクノロジー:

- [Typescript](https://www.typescriptlang.org/) JavaScript の使用体験は本当に退屈です。 しかし、typescript を使用すると、
- [Markdown](https://www.markdownguide.org/) 書くのに最適な言語
- [MDX](https://mdxjs.com/) を使用すると、マークダウン ファイルに jsx を記述することができます
- [Next.js](https://nextjs.org/) は Web サイトのメインフレームワークです
- [Tailwindcss](https://tailwindcss.com/)。 さらに、tailwindcss エコシステムのいくつかのツール (ヘッドレス UI、ヒーローアイコン、ヒーローパターンなど) も使用します。
- [Framer motion](https://www.framer.com/motion/) アニメーション作成用ライブラリ
- [Render](https://render.com/) 数回クリックするだけで postgresql データベースをセットアップします。 そして ORM[プリズマ](https://www.prisma.io/)
- [sentry.io](https://sentry.io/) はウェブサイトの追跡に使用されます

# グローバルレイアウトの構築

## 詳細

Web のレイアウトは 3 つの部分で構成されます。

- ヘッダー: Web サイト名、ナビゲーション、テーマスイッチャーが含まれます

- メイン: ページのコンテンツ

- フッター: 著者情報、著作権

私たちのほとんどは古い Web デザインを再利用しますが、次のような調整がいくつかあります。

- [ヒーロー パターン](https://heropatterns.com/) の背景 **回路基板** を使用します

- 古い Web のダーク モードとライト モードの代わりに、異なるテーマを使用します。

設定方法は非常に簡単で、CSS 変数アプリケーションです。

```css
/* 2 つのテーマを定義します: */
.theme-first {
  /*25 23 36 は rgb(25,23,36) を意味します */
  --カラーベース: 25 23 36;
  --color-surface: 31 29 46;
  --カラーテキスト: 38 35 58;
}

.theme-秒 {
  --カラーベース: 250 244 237;
  --color-surface: 255 250 243;
  --カラーテキスト: 242 233 222;
}

/* クラスでカラーテーマを使用します: */
.my-box {
  幅: 100ピクセル;
  高さ: 100ピクセル;
  背景: rgb(var(--color-base));
}
```

テーマを使用するには、テーマのクラス名を body タグに追加するだけです。 例えば：

```html
<body class="テーマファースト">
  <div class="my-box"></div>
</body>
```

tailwindcss を使用しているため、ファイル `tailwind.config.js` でもう 1 つの手順を設定する必要があります。

```js
 // クラス opacity-[value] を使用できるようにするには、この関数が必要です
関数 withOpacityValue(変数) {
  return ({ opacityValue }) => {
    if (opacityValue === 未定義) {
      `rgb(var(${variable}))`を返します;
    }
    return `rgb(var(${variable}) / ${opacityValue})`;
  };
}

 // テーマ内の変数 CSS の数を定義します。
テーマカラー = { にします
  ベース: withOpacityValue('--color-base')、
  表面: withOpacityValue('--color-surface')、
  テキスト: withOpacityValue('--color-text'),
  //...
};

module.exports = {
  ノイ・ズン: [
    './pages/**/*.{js,ts,jsx,tsx}',
    './components/**/*.{js,ts,jsx,tsx}',
  ]、
  テーマ： {
    伸ばす： {
      色: テーマの色、
    }、
  }、
  プラグイン: []、
};
```

使用：

```html
<button className="bg-base text-text p-3">Hello World</button>
```

最後に、ライブラリ [next-主題](https://github.com/pacocoursey/next-主題)を使用します。 わずか数行のコードでテーマを簡単に切り替えることができます。
